Pergunta 3: Gestão do Spanning-Tree (STP)

Se não for gerido, um switch de acesso antigo com o MAC address mais baixo pode tornar-se o Root, forçando todo o tráfego da rede a passar por um link lento e ineficiente.

Exame Recurso (02/07/2025)


Pergunta 1: VLANs e Endereçamento

    a) Comunicação PC4 e deb-1: Sim, a comunicação é possível. Como ambos estão na VLAN 1 e partilham o mesmo endereço de rede, o tráfego é encaminhado diretamente via Camada 2 (L2) através do link de trunk ou portas de acesso, sem necessidade de passar por um router.
    b) Comunicação PC4 e PC3: Não é possível. Embora tenham o mesmo endereço de rede IP, estão em VLANs diferentes (domínios de broadcast distintos). Para haver comunicação inter-VLAN, os pacotes têm de ser encaminhados por um router ou switch L3, e as interfaces virtuais (SVIs ou subinterfaces) não podem ter endereços IP da mesma sub-rede configurados simultaneamente.

Pergunta 2: Hierarquização do Encaminhamento

    a) Em que consiste: Consiste em dividir a infraestrutura de rede em camadas lógicas (Acesso, Distribuição e Core) ou em áreas de encaminhamento (como as áreas OSPF), em vez de ter uma rede plana onde todos os routers processam todas as rotas.
    b) Vantagens: As principais vantagens são a escalabilidade, a redução do tamanho das tabelas de encaminhamento (sumarização), a isolação de falhas (instabilidades numa área não afetam o cálculo de rotas noutras) e a otimização dos recursos de CPU dos equipamentos.

Pergunta 3: Encaminhamento Hierárquico OSPF

    Baseia-se na utilização de Áreas, sendo a Área 0 (Backbone) obrigatória para interligar as restantes. A sua importância para o desempenho reside no facto de limitar a inundação de LSAs (Link State Advertisements) a uma área específica e permitir que o algoritmo SPF (Shortest Path First) seja corrido apenas sobre uma base de dados menor, acelerando a convergência.

Pergunta 4: Rede Estruturada e Datacenter

    a) Camadas e Equipamentos: A rede teria as camadas de Acesso (switches L2 como o C2960 para ligar utilizadores), Distribuição (switches L3 para agregação e políticas) e Core (routers ou switches de alta performance para transporte rápido).
    b) Rede Lógica: Deve representar as interfaces virtuais (SVIs), as adjacências OSPF entre os routers R1/R2 e os switches de distribuição, e os links de trunking.
    c) Interligação do Datacenter: Deve ser interligado preferencialmente na camada de Core ou Distribuição, utilizando links redundantes e de alta largura de banda para garantir baixa latência e alta disponibilidade aos servidores.

Pergunta 5: Relatório de Migração IPv6

    A migração exige a ativação de Dual-Stack nos equipamentos (IPv4 e IPv6 em simultâneo). As alterações incluem:
        Gestão de Endereçamento: Passagem de 32 para 128 bits e uso de SLAAC ou DHCPv6.
        Tradução de Nomes: Atualização do DNS para suportar registos AAAA.
        Protocolos: Substituição do ARP pelo NDP (Neighbor Discovery Protocol) via mensagens ICMPv6.

Respostas Abertas:
L2 vs L3: Um switch L2 comuta frames baseando-se em endereços MAC (Hardware); um switch L3 pode também encaminhar pacotes IP (Routing) via hardware, sendo mais rápido que um router tradicional para tráfego inter-VLAN
.
SLAAC: O host envia um Router Solicitation. O router responde com um Router Advertisement contendo o prefixo da rede. O host combina esse prefixo com o seu Interface ID (ex: via EUI-64) para gerar o seu próprio IP global sem precisar de um servidor DHCP
.
Redundância Excessiva: Aumenta drasticamente os custos (15-25% extra), torna a gestão complexa (explosão de tabelas de routing) e pode causar problemas de convergência se as rotas redundantes forem anunciadas incorretamente antes de haver falhas reais
.
