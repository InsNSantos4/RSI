Questão #4 Estruturas de SO: microkernel. Qual afirmação descreve melhor um microkernel?

Estruturas de SO: microkernel
Qual afirmação descreve melhor um microkernel?

 Move o máximo de serviços (ex ficheiros e drivers) para user space e comunica via IPC
 Mete tudo no kernel para reduzir overhead
 Organiza o SO apenas em camadas fixas e imutáveis
 Elimina a necessidade de system calls


Questão #5 Estrutura modular (kernel com módulos carregáveis)Qual vantagem e tipicamente apontada para uma estrutura modular?

Estrutura modular (kernel com módulos carregáveis)
Qual vantagem e tipicamente apontada para uma estrutura modular?

 Menos eficiente porque exige message passing entre módulos
 Mais flexível e mais fácil de manter, com desempenho equilibrado
 Impossível adicionar funcionalidades em runtime
 Obriga a definir fronteiras rígidas entre camadas
